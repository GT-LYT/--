# 02 主题内容分析｜01 逻辑与 02 标签先分离

**核心问题**：2024 年全球可再生能源新增装机中，太阳能、风能与其余技术各占多少？

| 判断层 | 主判断 | 排除与说明 |
|---|---|---|
| 01 基础数据逻辑 | **编目型** | 数据按技术类别分组，一类一条；排序可按数值降序，但不因此成为编年型或字母表型 |
| 02 作品表现标签 | **比较型 Comparison** | 三类在同一单位和总量下并列比较；不是地图或时间轴 |
| 02 跨类型基础方法 | **ISOTYPE 式图像重复计量** | 1 枚图符=10 GW，同尺寸重复并明确小数余量；它**不是第18种类型** |
| 可选辅助 | 混合型 Mixed Charts | 如后续同时添加堆积条形图和重点数字，则可附加混合型；当前样稿只用重复图符及文字 |

- **研究结构**：技术类别 → 新增装机 GW → 相同分母的百分比 → 主导结构结论。
- **研究主张**：太阳能 452 GW，占可再生能源新增装机约 77.3%；风能 113 GW，约 19.3%。
- **数据边界**：本样本是“全球＋2024 年＋净新增装机容量”，不是日发电量、不是电力市场份额。
- **方法证据**：使用统一单元重复计量、明确单位及余量策略，因此可称现代 **ISOTYPE 式**方案；不声称是历史原作。

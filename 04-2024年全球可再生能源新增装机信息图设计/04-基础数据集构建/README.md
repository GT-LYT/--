# 04 基础数据集构建｜一列一个变量，一格一个值

- [基础数据集.csv](./基础数据集.csv)：3 条能源技术类别（太阳能、风能、其他合并余量）。
- [衍生指标.csv](./衍生指标.csv)：其他技术余量、三类占比、太阳能＋风能合计占比。
- [字段字典与统计规则](./字段字典.md)。

**原始值：** 585 GW 总量，太阳能 452 GW，风能 113 GW；**派生：** 其他 20 GW = 585−452−113。校验总和：452+113+20=585 GW。来源锁定 [IRENA 2025 年 3 月版](https://www.irena.org/-/media/Files/IRENA/Agency/Publication/2025/Mar/IRENA_DAT_RE_Capacity_Statistics_2025.pdf)。

**质量要求：** 禁止合并字段、禁止将数值与单位写在同一格、禁止将未观察到的具体水电/生物能/地热数值分摊到“其他”。

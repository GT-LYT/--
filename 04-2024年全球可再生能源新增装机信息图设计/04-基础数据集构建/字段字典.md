# 基础数据集字段字典

每行代表 **2024 年全球一种能源类别的净新增装机**。每列存一种变量，每格一个原子值：分类 ID、中文类名、英文类名、数值、单位、年份、地区、来源版本、证据状态。数值不附带 GW 文本；不把“太阳能 452 GW”写在同一格。

| 字段 | 类型 | 规则 |
|---|---|---|
| category_id | 名义 | 唯一稳定 ID，SOLAR/WIND/OTHER |
| category_zh/category_en | 文本 | 一格一个标签 |
| added_capacity | 数值 | GW；2024 年净新增容量，不是累计存量或发电量 |
| unit | 名义 | 全部填 GW |
| year | 整数 | 2024 |
| geography | 名义 | Global |
| source_edition | 名义 | 固定使用 IRENA_2025_March |
| evidence_status | 名义 | source_direct / calculated_residual |

**校验：** 452+113+20=585；百分比是从相同分母 585 算出的派生指标。20 GW 为总量减去两项的**合并余量**，不要把它称为独立统计的水电容量。原报告数据四舍五入，派生占比仅作制图计算，展示建议保留一位小数。

[公开来源](https://www.irena.org/-/media/Files/IRENA/Agency/Publication/2025/Mar/IRENA_DAT_RE_Capacity_Statistics_2025.pdf)；后来的版本有统计修订，本项目不跨版本混算。

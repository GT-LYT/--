# 04｜2024 年全球可再生能源新增装机信息图设计

**主题：** 2024 年世界新增可再生能源发电装机中，太阳能究竟占多少？ 公开数据源：IRENA《Renewable capacity statistics 2025》（2025 年 3 月版）；2024 年净新增容量 585 GW，太阳能 452 GW，风能 113 GW，其他类别合计余量 20 GW（派生）。**不可把“装机”表述为“实际发电量”。**

**双层分类：** 01 基础数据逻辑为**编目型**（按能源技术分类）；02 作品表现为**比较型**；额外标记 **ISOTYPE 式重复图符计量方法**（非第十八种类型）。

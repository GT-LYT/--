# 01 前期调研｜为什么研究新增装机？

**选题：2024 年全球可再生能源新增装机结构：太阳能主导了多少？** 公众容易把“发电量”“装机存量”“当年新增容量”混为一谈。本图只回答**2024 年新增可再生能源发电装机容量按技术如何分配**。

- 受众：关注能源转型的非专业读者与信息设计课程。
- 可调查的核心指标：2024 年新增装机总量、太阳能新增装机、风能新增装机、其余技术合计。
- 现实意义：从新增装机结构观察增长动力；**不据此推断发电量、排放量或各国贡献**。
- 来源可得性：IRENA 2025 年 3 月版 *Renewable capacity statistics 2025* 前言可读取上述数据；不需要杜撰采访。
- 图形交付规格：中文竖版 1200×860 SVG 试稿，采用三个类别的重复计量符号。

**调查清单（后续核实）：** 研究读者是否理解 GW、装机与发电量区别；测试每枚图符代表 10GW 的读数；征询图例和余量处理是否直观。

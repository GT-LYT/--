# 05 叙事框架搭建｜字段组合形成命题

| 模块 | 使用字段 | 读者问题 | 表达 |
|---|---|---|---|
| 1 标题与总览 | year + geography + total_added_capacity | 2024 年新增多少？ | 总数 **585 GW** 加上指标解释 |
| 2 核心发现 | category_zh + added_capacity | 太阳能贡献多大？ | 452 GW 和 77.3% 高亮 |
| 3 横向比较 | category_id + added_capacity + unit | 风能与其他有多少？ | 等尺寸符号重复列阵 |
| 4 解释与口径 | source_edition + evidence_status | 数据可靠吗？ | 来源、年份、净新增装机定义、余量备注 |

**推荐阅读顺序：** 问题（2024 年谁主导扩张）→ 总量（585 GW）→ 三组单位图符 → 77.3% 的主结论 → 来源与统计边界。读者无需依赖颜色才能比较。

**数值绑定：** “类别＋新增装机”对应大小比较；“类别＋占比”描述总体组成。**这里没有经纬度字段**，不应添加装饰性地图，也不应虚构国家分布。

## 硬性规则
先判五种逻辑的**唯一主归属**，再判表现形式标签，最后按需要评估 ISOTYPE、统计图形与 Gestalt。每件正式案例需原图来源及版权状态、逐图分析、原子化数据表和字段字典。**一行一记录、一列一字段、一格一值**，不可从样式推断不存在的数值或流向。

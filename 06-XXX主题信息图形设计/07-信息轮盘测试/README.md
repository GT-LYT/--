# 07-信息轮盘测试

## 目标
预留教师后续提供的信息轮盘评价标准，当前只建真实测试表与常规可读性检查。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 标准（待提供）、测试记录、版本差异、答题任务。
- **执行顺序：** 测试目标 → 受众任务 → 实测数据 → 修订方案（正式维度待补）。

## 内容与方法
当前只设计问卷题目、读图任务与观察表格。信息轮盘的正式定义由课程随后提供，未经确认不自造评分权重。

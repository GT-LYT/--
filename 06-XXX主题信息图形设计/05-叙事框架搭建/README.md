# 05-叙事框架搭建

## 目标
把多个字段组合成明确且有证据的视觉命题与阅读结构。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 主题/观点、字段组合、模块顺序、视觉焦点、证据和结论。
- **执行顺序：** 主题问题 → 数据主证据 → 辅助图 → 背景解释 → 统计边界。

## 内容与方法
如地名+longitude+latitude=地图定位；国家+GDP_USD=跨国比较；年份+value=年度趋势；类别+频数=编目比较。每个叙事模块必须有可复核的字段组合。

## 阶段质量门槛
- [ ] 每项命题可指回数据列
- [ ] 无数据支持的因果未写成结论

# 08-设计实施

## 目标
产出草图、低保真、改版和最终成品；验收数据映射、版权及设计文件可编辑性。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 草图、设计源文件、SVG/PDF/PNG输出、版本登记、检查表。
- **执行顺序：** 草图 → 校验统计关系 → 视觉迭代 → 测试 → 导出 → 归档。

## 内容与方法
保留设计源文件、版本号、使用的公开数据版本、导出分辨率、标题/图注/来源、版权说明和可访问性检查。

## 阶段质量门槛
- [ ] 有设计版本
- [ ] 交付文件可预览
- [ ] 源数据与成品数字一致

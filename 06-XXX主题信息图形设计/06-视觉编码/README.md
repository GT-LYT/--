# 06-视觉编码

## 目标
把数据映射为点线面体、色彩、文字、图形图像与统计图，并设计版式与视觉风格。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 视觉编码矩阵、图符字典、图形选择、风格方案与实验。
- **执行顺序：** 数据字段 → 视觉变量 → 表现形式 → 排版 → 可访问性与误读检验。

## 内容与方法
记录点线面体的变量映射、长度/面积刻度、色彩语义、字体与行距字距、图符/摄影的证据、统计图和图例。使用 ISO 标准图标或 ISOTYPE重复计量时分别说明方法。

## 阶段质量门槛
- [ ] 数量尺度正确
- [ ] 引线语义明确
- [ ] ISO 与 ISOTYPE 区分
- [ ] Gestalt 对应数据关系

# 02-主题内容分析

## 目标
与大模型讨论五类基础逻辑、十七类表现标签、具体平面/摄影/插画风格及适配性。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 五大逻辑主归属、02主与辅标签、视觉风格、排除其他标签的理由。
- **执行顺序：** 结构字段 → 五类逻辑 → 02市场形式 → 03/05方法标签与风格。

## 内容与方法
讨论顺序、层级、分类、字母索引和地理位置哪种真正组织信息。02 的比较、混合、流程、照片、词云等是表现形式；平面/摄影/手绘属于风格；ISOTYPE 与 Gestalt 属于方法。

## 阶段质量门槛
- [ ] 主归属理由有证据
- [ ] 没有把照片、词云或ISOTYPE当新数据逻辑

# 01-前期调研

## 目标
建立现实问题、传播情境、受众和资料可得性。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 调研资料、对象与问题、现有图形案例、选题边界。
- **执行顺序：** 研究问题 → 受众 → 资料证据 → 选题可行性。

## 内容与方法
先讨论选题现实性、受众需求、调查范围及可访问数据。记录报道时点和可能的数据偏差，案例来源与用户提供材料分别列明。

## 阶段质量门槛
- [ ] 研究问题清楚
- [ ] 来源可访问
- [ ] 没有把问题与立场混为一谈

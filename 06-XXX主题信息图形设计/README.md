## 统一分类方式
01：先判断五种基础数据组织逻辑；02：再标注一个主表现类型和辅标签；03：ISOTYPE 是图像转译与符号方法；04：统计与计算；05：Gestalt 用于视觉组织原则。平面、摄影、插画等是独立的风格选择，不应被误判为数据逻辑。

## 记录纪律
- **一行一个最小对象、一列一个字段、一格一个值。** 图像本体单独存，表格列记录图像路径/ID。
- 明确记录来源、年份、口径、主键、单位、计算公式和缺失值，不从画面猜数据。
- 用字段构成叙事：地名+经纬度→空间定位；国家+GDP→经济比较；时间+数值→变化趋势。
- 整体过程：调研→内容分析→来源→基础数据→叙事→视觉编码→信息轮盘测试（课程标准待补）→设计实施。

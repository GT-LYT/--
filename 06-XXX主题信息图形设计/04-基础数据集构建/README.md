# 04-基础数据集构建

## 目标
原子化、标准化数据表并使每个字段可直接绑定可视变量。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** CSV/XLSX、字段字典、主键、单位、来源、缺失值规则。
- **执行顺序：** 一行一对象/观测，一列一字段、一格一值 → 关联键 → 验证。

## 内容与方法
原始观测与聚合结果分表，保留 ID、关联键和字段字典。名义、量化、图像路径、文本各自可以为一格一个数据；一格不能存“姓名+GPS”或“金额+单位”。

## 阶段质量门槛
- [ ] 无复合字段
- [ ] 主键唯一
- [ ] 经纬度与单位分列
- [ ] 转换有公式

# 03-数据搜集

## 目标
建立公共数据集、文本文献与自建数据三类来源，区分引用与真实采集。

## 输入与产出
- **输入：** 上一阶段文档、可靠资料及当前研究问题。
- **产出：** 原始数据文件、出版物、逐项来源、版本及授权记录。
- **执行顺序：** 公共/文本/自建 → 来源清单 → 可信度 → 采集时间与许可证。

## 内容与方法
为数据列出 publication_date、access_date、source_url、license、geography、period 和 quality_status。收集文本与自建问卷时，区分原始样本和抽象总结。

## 阶段质量门槛
- [ ] 原始数据可追溯
- [ ] 数据未虚构
- [ ] 原图版权与数据使用权分开记录

# 06 视觉编码与可复用方法

- **点**：不编码GDP数值。必要时仅作为行项引导或脚注编号。
- **线**：每行比较使用同一零基线；细分隔线用于版式秩序，绝不是贸易流向或政治关系。
- **面**：横条长度与GDP成线性比例；100%构成条的各段长度与占世界份额成线性比例，组成总量为100%。
- **体**：不使用3D立体柱，以免透视造成长度误读。
- **颜色**：深蓝突出美国、深红突出中国，其余前十统一中性蓝灰，“其余世界”浅灰。颜色为阅读层级，不代表政治立场、联盟或冲突关系。
- **字体排版**：中文名/英文名独立文本层；图例、标题和精确值清晰分层，数字右对齐。
- **统计图形**：上方100%堆积条回答“整体占比”，下方水平条形图回答“经济体之间绝对规模”，二者分母/基线不同，不要混同。
- **ISOTYPE**：本主题暂不采用。它是基础图符计量方法，不能因有多个条形图就套该标签。

**制作计算：** `bar_width = max_width × gdp_usd_million / max_gdp_usd_million`；`share = gdp_usd_million / world_gdp × 100`。标签可把原表的百万美元换算为万亿美元展示：`trillion = million / 1,000,000`。

**反例检查：** 截断横条轴线、不标记美元单位、使用不同版本的世界GDP作分母、用地理轮廓面积代表GDP、把汇率变动解释为真实经济增长。

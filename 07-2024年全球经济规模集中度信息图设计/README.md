# 07｜全球经济版图：2024年GDP前十经济体占世界经济多少？

**政治经济主题：** 经济规模集中度。**数据源：** 世界银行 World Development Indicators，《Gross domestic product 2024》，数据发布于 **2025年12月15日**。GDP以**现价美元（nominal GDP, current USD）**衡量。GDP不是政治权力或居民富裕程度指标。

**分类：** `01 编目型`（经济体类别） → `02 比较型`（统一尺度横条）＋`混合型`（总体构成与排名组合）。**ISOTYPE不启用**，因为本主题使用常规长度编码更便于准确比较。

## 研究发现（精确口径）

世界GDP为**110,982,661百万美元**；前十合计**73,774,602百万美元**，占**66.5%**，其余世界约占**33.5%**。美国与中国合计占全球约**42.8%**。以上派生值由同一世行报告计算得到，不能以百分比推断国家政治权力。

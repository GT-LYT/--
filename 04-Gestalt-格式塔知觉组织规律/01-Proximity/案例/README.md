# 01 接近律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 把一组教育程度×就业率的条形图分成三个年份，每个年份内两根条间距为8单位、不同年份组之间间距为30单位，读者优先看到三个年份组。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 视觉系统利用局部空间距离建立边界；组内距离与组间距离的对比通常比单一绝对像素值更重要。

**教学前后对照：**
- 待修改版：六根条采用完全等距间隔，年份之间的分组不明显。
- 建议修改版：把两条同年条形设为小间距、不同年组留更大间距，并在组下标明年份。

**叙事目标：** 先辨认年份组，再在组内比较两个指标，最后跨年份读变化。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

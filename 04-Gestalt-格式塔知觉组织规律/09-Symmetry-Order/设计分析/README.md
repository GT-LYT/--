# 09 对称与秩序｜设计分析

## 1. 机制识别
镜像对应、共同轴线与可预测的网格帮助建立完整结构，但对称不意味着两侧数值相同。

## 2. 图形变量拆解
点：镜像或重复网格保持稳定间距；线：共享比较轴或镜像基线；面：两侧对称区块可增强对照；色彩：对照双方有辨识度但不过分偏袒；文字：相同信息层级采用一致字号。

## 3. 视觉叙事架构
建立中轴→逐年龄组进行左右对照→观察结构差异→解释时间与人口背景。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 左右人口条使用不同尺度或不对齐的年龄组，以表面对称掩盖口径不一致。 | 固定同一年龄分组、相同单位和左右镜像尺度，并标注不同组别。 |
| 语义风险 | 为了维持左右画面长度近似，调整各组条形比例，破坏统计真实性。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 强行居中对称会压缩长地名或数值，增加标签遮挡。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 检查左右轴刻度、分母、年龄分组是否严格一致，再做版式均衡判断。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。为了维持左右画面长度近似，调整各组条形比例，破坏统计真实性。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

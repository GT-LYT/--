# 08 连接律｜Law of Connectedness

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**由一条线、引线或其他可见连接体直接相连的元素，更容易被感知为具有同一对象身份或某种关系。**

- **作用机制：** 显式连线是一种强视觉关系线索；其语义必须通过数据字段或图例说明，不能自动推断为因果、流量或时间。
- **原则类别：** 显式连接型分组。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：端点准确落在对象；线：连接须单对单可追溯，使用端点、箭头和线型区分不同关系；面：避免连线遮挡；色彩：连接线中性化以减少与数量编码竞争。

## 三｜视觉叙事
先读上方营收圆，再顺引线回到地图点位，建立“谁—位于哪里”的对应。

## 四｜典型应用与反例
- **教学分析情境：** 《Power Centers of the Fortune 500》海报的比例圆通过细曲线连接到美国地图对应都会区点位，线表示**同一都市区身份的对应**，不是资金流动。
- **反例／误用：** 给普通地理引线加单向箭头，误使读者理解为资金输送或人口迁移。
- **可用性边界：** 多线交叉、端点密集或者指示线断开会引起对象错配。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对显式连接型分组的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 随机指明圆形，请读者指出地图对应点，统计误配率；仔细检查所有引线终点。

# 08 连接律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 《Power Centers of the Fortune 500》海报的比例圆通过细曲线连接到美国地图对应都会区点位，线表示**同一都市区身份的对应**，不是资金流动。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 显式连线是一种强视觉关系线索；其语义必须通过数据字段或图例说明，不能自动推断为因果、流量或时间。

**教学前后对照：**
- 待修改版：将营收圆形放在地图外，却不提示它们对应地图上哪个都市区。
- 建议修改版：用明确引线连接每个营收圆与其地理位置，并让数值仍由圆面积/数字而非线长表达。

**叙事目标：** 先读上方营收圆，再顺引线回到地图点位，建立“谁—位于哪里”的对应。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

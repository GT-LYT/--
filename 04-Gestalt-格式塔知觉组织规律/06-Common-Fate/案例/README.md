# 06 共同命运律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 一幅交互式迁徙图中，符合相同迁徙季节的个体点随时间同向移动；只有确有时间与方向数据时才可设计此动画。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 共同运动提供时间上的强关系线索；同步动画必须源自真实的共同状态或同一事件。

**教学前后对照：**
- 待修改版：随机动画驱动各点同步移动，只是装饰，暗示数据中不存在的共同方向。
- 建议修改版：使用每个观测对象的真实时间和位移字段驱动动画，并在静态版显示轨迹与日期。

**叙事目标：** 变化开始→共同运动显现→差异路线分离→与事件解释对照。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

# 07 共同区域律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 疫情信息图把“当日新增”“累计确诊”“检测量”分别置于清晰分组的卡片区域，前提是每张卡片内部的单位与口径一致。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 容器边界建立可见的共同归属关系；在某些布局中可压过接近或相似性线索。

**教学前后对照：**
- 待修改版：将死亡人数与检测人数放在同一无说明底色区块，容易被误认为同一统计口径。
- 建议修改版：按指标口径分成独立面板，明确时段、单位、分母和数据来源。

**叙事目标：** 先识别板块主题，再读取卡片内数字，最后跨板块对照而不混合单位。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

# 01 前期调研：经济规模的集中

## 研究动机

政治经济讨论经常比较不同经济体的产出规模，但“GDP规模”“人均收入”“购买力”和“政治影响力”是不同概念。本选题回答：**2024 年世界名义GDP有多大比例集中在经济规模最大的十个经济体？**

## 受众与场景

- 受众：信息设计课程、经济新闻读者、公共政策入门者。
- 场景：竖版专题信息图、经济报道插图或课堂展示。
- 需要读者理解：世界总量、前十合计、美中经济规模、其余世界占比。
- 排除：不借GDP推断政治制度优劣、福利水平、军事实力或外交权力，也不将现价美元视为固定汇率不变的长期实质增长。

## 可行性

公开来源为世界银行世界发展指标（WDI）2024 GDP榜单，**发布版本为2025年12月15日**。原刊附有前十经济体、世界合计，足够直接重算集中比例。[查看官方PDF](https://datacatalogfiles.worldbank.org/ddh-published/0038130/DR0046441/GDP.pdf)。

## 待验证研究问题

- 不展示原图时读者能否准确分辨“份额”和“增长率”？
- 用前十名与其余世界构成条是否比单纯GDP排名更容易理解“集中”？
- 是否需要解释“名义GDP”与 PPP、人均GDP的差别？

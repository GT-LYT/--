## 方法专项与技术层
[03 ISOTYPE 独立方法](../03-ISOTYPE信息图/README.md)研究规范化图符及信息转译，**不是 02 的第18个标签**。[04 统计图形](../04-统计图形分析/README.md)负责数值处理；[05 Gestalt](../05-Gestalt视觉组织原则/README.md)负责感知组织。

## 一图一档
每件已验证案例应具有可查的原作来源及版权状态、分析.md、基础数据集.csv、数据字典.md、必要附属指标；允许官方外链，但不得声称原图 JPG 已上传。多个表现标签只给同一案例作交叉链接，不重复复制第三方原图。

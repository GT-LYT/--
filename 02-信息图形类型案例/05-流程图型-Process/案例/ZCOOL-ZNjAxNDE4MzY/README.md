## 01 主数据逻辑
**编年型/程序顺序**。博饼活动按规则或流程展开，不同环节之间的先后关系具有解释作用。

## 02 表现标签与分类证据
**流程图型 Process**，由作者本人明确说出了流程拆解与流程图制作；不仅是对图片风格的推测。

## A—E 五维
- **A 数据逻辑：** 操作节点 `step_id`、事件次序 `order_key`、条件转移 `condition_id`。
- **B 统计和计算：** 尚无原始博饼统计数据；不从C4D模型尺寸推导概率。
- **C 视觉编码：** 流程节点表示行动或状态，箭头表示实际后继关系，三维场景是文化语境辅助；颜色若无图例不当作量值。
- **D 数据架构：** 区分 `step_id,step_name,order_key,condition_id,source_id`；规则转换用独立边表。
- **E 视觉叙事：** 先介绍博饼文化→解释参与步骤→读规则条件→结合场景说明活动结果。

## 反例与复现方法
不要将三维透视误当准确空间尺寸，也不要把非规则限定的虚拟箭头当作真实流程。复现时先核原文规则，再做流程图与场景，最后由读者完成规则追踪任务。

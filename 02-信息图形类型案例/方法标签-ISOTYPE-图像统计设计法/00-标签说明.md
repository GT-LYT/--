# ISOTYPE｜图像统计与视觉教育设计方法

**标签身份：基础设计方法／视觉编码方法，不是信息图形的一种类型。** ISOTYPE（International System of Typographic Picture Education）是一套以标准化图像符号组织、转换和解释信息与统计数据的设计方法，历史上起源于维也纳图像统计法，1935 年采用 ISOTYPE 名称。它可跨越本仓库 01 的五种数据逻辑和 02 的多种图形表现标签，不能把它作为第六种基础数据逻辑或第十八种并列信息图形类型。

## 研究对象与历史定位

- 主要历史人物：Otto Neurath（总体理念与教育方法）、Marie Reidemeister／Marie Neurath（将信息转化为图像表达的 transformer 工作）、Gerd Arntz（系统化、可识别的图符设计）。
- 主要研究单位是**信息转换与图像编码方法**，而非“图中存在扁平图标”这一视觉外观。
- 资料：[Isotype Revisited：Introduction](https://isotyperevisited.org/2012/08/introduction.php)；[维也纳大学：Isotype 的起源、发展与影响](https://isotype.univie.ac.at/en/abstract/)；[斯坦福哲学百科：Neurath 的视觉教育](https://plato.stanford.edu/archives/spr2026/entries/neurath/visual-education.html)。

## 核心方法及其适用边界

| 方法 | 可操作规则 | 验证要点 |
|---|---|---|
| 图像转译（transformation） | 先定义读者问题、对象、变量与单位，再由设计人员选择图符及编排 | 不把数据输入直接视作已完成的设计 |
| 符号标准化 | 同类对象使用相同轮廓、尺寸、视角和图例；使用可被识别的代表性图像 | 图符代表什么，是否跨页面一致 |
| **重复计量** | 每枚相同尺寸的象形符号代表同一计量单位；较大数值原则上使用更多符号 | 图例是否写清「1 枚 = N 单位」；不足一枚如何处理 |
| 数量对比 | 避免单靠**放大同一图符**来表示数量增加；比较数量时优先以等尺寸图符重复 | 不能把面积圆或比例放大头像误称为 Isotype 计数 |
| 语义与数量双编码 | 形状负责辨认对象，重复次数负责数量；色彩可用于区分类别但不应取代清楚的图例 | 是否区分“是什么”和“有多少” |
| 网格与阅读顺序 | 对齐行列、保持符号间距、安排分组和对照；地图组织时需另说明地理位置的角色 | 读者能否沿稳定顺序比较 |
| 读者教育 | 简化复杂知识，同时保留必要说明和可追溯数据口径 | 是否损失统计精度、隐去基数或制造误导 |

**重要限定：** ISOTYPE 不是所有图标设计的统称；ISO 标准化图符与 ISOTYPE 不是同一概念。单个图标、普通插画、图标列表，或仅把图标画得很扁平的作品，都**不能自动认定**采用了 ISOTYPE 设计方法。现代设计也可能借鉴其原则，而非属于历史上严格意义的 Isotype 原作。

## 入库时怎么使用这个标签

1. **先判断 01**：编年、层级、编目、字母表、地理中的主信息组织逻辑。
2. **再判断 02 表现形式**：混合图、列表、时间轴、地图等。
3. **最后独立判断方法标签**：有无标准化图符、是否重复计量、单位是否统一、图像转译是否可观察。
4. **证据等级**：历史原作且来源明确→「历史 Isotype」；具备明确的重复图符计量机制→「Isotype 式方法」；仅扁平符号→「图符化设计，未达到方法标签条件」。
5. **案例互链**：只在逐图分析中说明哪部分证据支持标签，不能仅因为作品属于“混合型”就自动附加 ISOTYPE。

## 制作流程

确定解释问题 → 检查数据粒度及总量 → 定义每枚图符的计量单位 → 设计与标准化图符 → 计算重复次数与余量处理 → 排列网格、添加分组与图例 → 校验统计单位、符号数量和读者理解。

计算示例：若一枚图符代表 10,000 人、记录值为 50,000 人，则绘制 5 枚等尺寸图符。若记录值为 54,000 人，应事先说明剩余 4,000 人采用部分符号、单独数字注释还是其他一致的舍入规则，不能无标记地直接画 5 枚并冒称精确值。

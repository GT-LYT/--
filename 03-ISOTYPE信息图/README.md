# 03｜ISOTYPE独立图像统计设计方法

独立研究国际图像文字教育系统（International System of Typographic Picture Education）以及从维也纳图像统计法发展而来的图符语言。**ISOTYPE 不是 01 第六种逻辑，也不是 02 第十八种表现类型**。本结构参考 [Infographic-Style-Repository 的 ISOTYPE 专项](https://github.com/fengbaifan/Infographic-Style-Repository/tree/main/03-ISOTYPE信息图)，根据本库已有的方法研究重写。

- [概念、信息转译和图像语法](./00-ISOTYPE概念与方法.md)
- [历史与文献](./01-历史与文献/README.md)
- [图符语言与编码](./02-图符语言与视觉编码/README.md)
- [案例研究](./03-案例研究/README.md)
- [设计实践](./04-设计实践/README.md)

方法框架：原始资料→受众与目的→基础数据结构→统一图符语义→固定单位重复/排布→图例和文字→验证。不把 ISO 公共导视图标等同于 ISOTYPE，也不把扁平画风等同于统计图符计量。

# Gestalt｜跨原则对照实验

研究不同知觉线索的竞争与协同，不通过直觉宣称某条规则总是优于另一条。

| 对照 | 固定量 | 操作变量 | 读者任务 |
|---|---|---|---|
| 接近 vs 相似 | 数据和位置轴 | 组间距、类别色 | 判定同组成员 |
| 接近 vs 共同区域 | 元素数量、标记 | 边框、留白 | 判断哪些属于一个统计组 |
| 连续 vs 连接 | 真实拓扑与端点 | 路线曲率、引线形式 | 正确追踪路径或对象 |
| 图底 vs 相似 | 各对象数值 | 对比度、类色 | 定位关键证据 |
| 平行 vs 同步 | 时间点及数据 | 平行方向、同步动效 | 区分空间平行与时间同步 |

记录 `experiment_id,design_version,variable,participant_code,task,correct,time_seconds,notes`；未开展时不填写虚构测量值。[规则总览](../README.md)。

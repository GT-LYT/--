# 07 共同区域律｜Law of Common Region

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**处于同一个视觉边界或共享背景区域内的元素倾向于被看作同一组，即使它们并非最近邻或外观不同。**

- **作用机制：** 容器边界建立可见的共同归属关系；在某些布局中可压过接近或相似性线索。
- **原则类别：** 边界内分组。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：在同一面板中的点被认为相关；线：边框围合但不伪造成数据连接；面：浅底色或容器区隔模块；色彩：用柔和共同区域背景；排版：边界与文字标签一致。

## 三｜视觉叙事
先识别板块主题，再读取卡片内数字，最后跨板块对照而不混合单位。

## 四｜典型应用与反例
- **教学分析情境：** 疫情信息图把“当日新增”“累计确诊”“检测量”分别置于清晰分组的卡片区域，前提是每张卡片内部的单位与口径一致。
- **反例／误用：** 同框呈现无关但容易混淆的百分比，让读者误认为共享分母。
- **可用性边界：** 卡片太多时，画面会出现容器噪声，读者难以发现主要结论。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对边界内分组的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 让测试者判断两项指标是否同组或同分母，检查错误归组率。

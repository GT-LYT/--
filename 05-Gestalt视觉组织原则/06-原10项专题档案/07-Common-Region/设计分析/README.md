# 07 共同区域律｜设计分析

## 1. 机制识别
容器边界建立可见的共同归属关系；在某些布局中可压过接近或相似性线索。

## 2. 图形变量拆解
点：在同一面板中的点被认为相关；线：边框围合但不伪造成数据连接；面：浅底色或容器区隔模块；色彩：用柔和共同区域背景；排版：边界与文字标签一致。

## 3. 视觉叙事架构
先识别板块主题，再读取卡片内数字，最后跨板块对照而不混合单位。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 将死亡人数与检测人数放在同一无说明底色区块，容易被误认为同一统计口径。 | 按指标口径分成独立面板，明确时段、单位、分母和数据来源。 |
| 语义风险 | 同框呈现无关但容易混淆的百分比，让读者误认为共享分母。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 卡片太多时，画面会出现容器噪声，读者难以发现主要结论。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 让测试者判断两项指标是否同组或同分母，检查错误归组率。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。同框呈现无关但容易混淆的百分比，让读者误认为共享分母。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

# 03 良好连续律｜设计分析

## 1. 机制识别
方向延续与平滑切线降低了路径识别成本，交叉处尤其容易形成连贯线路的判断。

## 2. 图形变量拆解
点：按可追踪轨迹排列；线：使用有连续切线的折线或曲线；面：顺连续路径组织区块；色彩：同线路颜色一致；引线：少交叉并明确终点。

## 3. 视觉叙事架构
沿路径进入→经过关键节点→到达目的节点；适用于路线或连续序列，而不是所有分类列表。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 相关路线频繁断开、急转、换色，读者难以判断延续关系。 | 在不伪造真实拓扑的前提下平滑路径，保持同线颜色一致并标换乘节点。 |
| 语义风险 | 用平滑曲线把只有离散类别的数据点连起来，暗示不存在的连续变化。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 多条曲线在密集交叉点仍会混淆，应增加路径直连标签。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 给定起点让测试者沿图追踪到终点，记录错误换线次数。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。用平滑曲线把只有离散类别的数据点连起来，暗示不存在的连续变化。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

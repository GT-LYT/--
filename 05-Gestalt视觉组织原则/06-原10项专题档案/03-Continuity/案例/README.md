# 03 良好连续律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 地铁线路示意图中的同一线路穿过换乘站继续延伸，线色和方向保持连续，帮助观察者沿路径追踪。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 方向延续与平滑切线降低了路径识别成本，交叉处尤其容易形成连贯线路的判断。

**教学前后对照：**
- 待修改版：相关路线频繁断开、急转、换色，读者难以判断延续关系。
- 建议修改版：在不伪造真实拓扑的前提下平滑路径，保持同线颜色一致并标换乘节点。

**叙事目标：** 沿路径进入→经过关键节点→到达目的节点；适用于路线或连续序列，而不是所有分类列表。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

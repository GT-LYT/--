# 03 良好连续律｜Law of Good Continuation

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**当点、线段或轮廓可以沿平滑而连续的方向延伸时，观察者倾向于把它们看作同一条视觉路径。**

- **作用机制：** 方向延续与平滑切线降低了路径识别成本，交叉处尤其容易形成连贯线路的判断。
- **原则类别：** 路径与方向连续型组织。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：按可追踪轨迹排列；线：使用有连续切线的折线或曲线；面：顺连续路径组织区块；色彩：同线路颜色一致；引线：少交叉并明确终点。

## 三｜视觉叙事
沿路径进入→经过关键节点→到达目的节点；适用于路线或连续序列，而不是所有分类列表。

## 四｜典型应用与反例
- **教学分析情境：** 地铁线路示意图中的同一线路穿过换乘站继续延伸，线色和方向保持连续，帮助观察者沿路径追踪。
- **反例／误用：** 用平滑曲线把只有离散类别的数据点连起来，暗示不存在的连续变化。
- **可用性边界：** 多条曲线在密集交叉点仍会混淆，应增加路径直连标签。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对路径与方向连续型组织的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 给定起点让测试者沿图追踪到终点，记录错误换线次数。

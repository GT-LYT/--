# 08 连接律｜设计分析

## 1. 机制识别
显式连线是一种强视觉关系线索；其语义必须通过数据字段或图例说明，不能自动推断为因果、流量或时间。

## 2. 图形变量拆解
点：端点准确落在对象；线：连接须单对单可追溯，使用端点、箭头和线型区分不同关系；面：避免连线遮挡；色彩：连接线中性化以减少与数量编码竞争。

## 3. 视觉叙事架构
先读上方营收圆，再顺引线回到地图点位，建立“谁—位于哪里”的对应。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 将营收圆形放在地图外，却不提示它们对应地图上哪个都市区。 | 用明确引线连接每个营收圆与其地理位置，并让数值仍由圆面积/数字而非线长表达。 |
| 语义风险 | 给普通地理引线加单向箭头，误使读者理解为资金输送或人口迁移。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 多线交叉、端点密集或者指示线断开会引起对象错配。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 随机指明圆形，请读者指出地图对应点，统计误配率；仔细检查所有引线终点。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。给普通地理引线加单向箭头，误使读者理解为资金输送或人口迁移。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

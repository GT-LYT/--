# 09 对称与秩序｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 人口金字塔用年龄组作为共同中轴参照，两侧水平条显示不同性别人数，镜像布局使每个年龄组便于比较。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 镜像对应、共同轴线与可预测的网格帮助建立完整结构，但对称不意味着两侧数值相同。

**教学前后对照：**
- 待修改版：左右人口条使用不同尺度或不对齐的年龄组，以表面对称掩盖口径不一致。
- 建议修改版：固定同一年龄分组、相同单位和左右镜像尺度，并标注不同组别。

**叙事目标：** 建立中轴→逐年龄组进行左右对照→观察结构差异→解释时间与人口背景。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

# 06 共同命运律｜Law of Common Fate

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**运动方向、速度或变化方式相近的元素更容易被感知为同一组；在静态设计中，相同朝向只能作为较弱的类比，不应直接等同运动。**

- **作用机制：** 共同运动提供时间上的强关系线索；同步动画必须源自真实的共同状态或同一事件。
- **原则类别：** 共同行为分组。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：同步移动的散点表达共同轨迹；线：动态路径同向而明确时间轴；面：群组整体运动与单项运动区分；色彩：辅助手势而非代替变化数据；动画：统一帧率及起止时间。

## 三｜视觉叙事
变化开始→共同运动显现→差异路线分离→与事件解释对照。

## 四｜典型应用与反例
- **教学分析情境：** 一幅交互式迁徙图中，符合相同迁徙季节的个体点随时间同向移动；只有确有时间与方向数据时才可设计此动画。
- **反例／误用：** 把不同国家GDP的静态排名条同时向右运动，暗示它们经历了同一增长趋势。
- **可用性边界：** 无运动偏好用户、静态截图或动画无法播放时，共同命运信息可能完全丢失。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对共同行为分组的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 以暂停帧和完整动画分别测试组别辨认；遵守减少动态效果偏好。

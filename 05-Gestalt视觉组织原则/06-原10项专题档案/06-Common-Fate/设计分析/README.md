# 06 共同命运律｜设计分析

## 1. 机制识别
共同运动提供时间上的强关系线索；同步动画必须源自真实的共同状态或同一事件。

## 2. 图形变量拆解
点：同步移动的散点表达共同轨迹；线：动态路径同向而明确时间轴；面：群组整体运动与单项运动区分；色彩：辅助手势而非代替变化数据；动画：统一帧率及起止时间。

## 3. 视觉叙事架构
变化开始→共同运动显现→差异路线分离→与事件解释对照。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 随机动画驱动各点同步移动，只是装饰，暗示数据中不存在的共同方向。 | 使用每个观测对象的真实时间和位移字段驱动动画，并在静态版显示轨迹与日期。 |
| 语义风险 | 把不同国家GDP的静态排名条同时向右运动，暗示它们经历了同一增长趋势。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 无运动偏好用户、静态截图或动画无法播放时，共同命运信息可能完全丢失。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 以暂停帧和完整动画分别测试组别辨认；遵守减少动态效果偏好。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。把不同国家GDP的静态排名条同时向右运动，暗示它们经历了同一增长趋势。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

# 01 接近律｜设计分析

## 1. 机制识别
视觉系统利用局部空间距离建立边界；组内距离与组间距离的对比通常比单一绝对像素值更重要。

## 2. 图形变量拆解
点：同一类别点阵在空间上聚集；线：不同分组间不必强加连线；面：组间留白构成隐性边界；色彩：可保持相同颜色以检验是否单靠距离就能分组；排版：数值标签应更靠近所属标记。

## 3. 视觉叙事架构
先辨认年份组，再在组内比较两个指标，最后跨年份读变化。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 六根条采用完全等距间隔，年份之间的分组不明显。 | 把两条同年条形设为小间距、不同年组留更大间距，并在组下标明年份。 |
| 语义风险 | 把不同口径的统计量挤在一起，造成它们可直接比较或属于同一个组的误解。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 在移动端缩放后，组间留白变窄，原来的分组可能失效。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 量化测试能否正确说出每个数值对应的组；缩小到手机宽度检查间距比。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。把不同口径的统计量挤在一起，造成它们可直接比较或属于同一个组的误解。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

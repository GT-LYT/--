# 01 接近律｜Law of Proximity

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**在其他条件大致相当时，空间距离较近的元素更容易被知觉为同一组，而不是与较远的元素配对。**

- **作用机制：** 视觉系统利用局部空间距离建立边界；组内距离与组间距离的对比通常比单一绝对像素值更重要。
- **原则类别：** 空间邻近型分组。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：同一类别点阵在空间上聚集；线：不同分组间不必强加连线；面：组间留白构成隐性边界；色彩：可保持相同颜色以检验是否单靠距离就能分组；排版：数值标签应更靠近所属标记。

## 三｜视觉叙事
先辨认年份组，再在组内比较两个指标，最后跨年份读变化。

## 四｜典型应用与反例
- **教学分析情境：** 把一组教育程度×就业率的条形图分成三个年份，每个年份内两根条间距为8单位、不同年份组之间间距为30单位，读者优先看到三个年份组。
- **反例／误用：** 把不同口径的统计量挤在一起，造成它们可直接比较或属于同一个组的误解。
- **可用性边界：** 在移动端缩放后，组间留白变窄，原来的分组可能失效。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对空间邻近型分组的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 量化测试能否正确说出每个数值对应的组；缩小到手机宽度检查间距比。

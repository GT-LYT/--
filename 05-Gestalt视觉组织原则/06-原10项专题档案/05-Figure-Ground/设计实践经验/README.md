# 05 图形—背景关系｜设计实践经验与操作规程

> 当前为 **复现实验设计建议**，并非已经实施的用户研究。“预期效果”不等于验证结论。

## 可复现的练习任务
**目标：** 缩略图识别第一视觉焦点，灰度检查、文本对比检查和地图小点可见性检查。

### A｜固定输入
- 先建立具有稳定 ID 的数据记录；保留原始值、单位、分类、注释。
- 固定导出画布尺寸和图例，不改变统计结果。
- 记录版式参数，例如组间距、字号、线宽、对比度、颜色、对齐或动画帧率。

### B｜对照制作
- **版本 0：** 地图、辅助网格、所有圆与长段注释同等强度，读者缺乏视觉入口。
- **版本 1：** 降低非关键底图对比、保留主体点和关键数字的清晰边缘，并维持可读图例。

### C｜测试任务
缩略图识别第一视觉焦点，灰度检查、文本对比检查和地图小点可见性检查。

建议分别在桌面宽屏、移动窄屏、灰度打印情境下进行；有时间序列或动效时提供静态版本。

### D｜实测字段（未测试）
| 字段 | 记录方式 |
|---|---|
| version_id | v0 / v1 |
| viewer_id | 匿名编号，不存真实姓名 |
| test_task | 事先固定的读图任务 |
| correct | 0/1，按预先确定的答案评分 |
| response_time_seconds | 从展示至确认答案的秒数 |
| observation | 对应的错误归组、路径错配或解释偏差 |
| revision | 是否需要改版及具体理由 |

**不应预填测试成功率或改善幅度**，也不把设计者个人偏好称为用户实证。

## 常见误区
把背景上的小比例地区颜色变淡到几乎消失，造成选择性隐瞒。

## 方法回写条件
新增真实案例或完成测试后，再依据数据重新审视“定义—编码—叙事—反例”的适用边界；记录证据、日期、修改原因，避免只追加符合预期的结果。

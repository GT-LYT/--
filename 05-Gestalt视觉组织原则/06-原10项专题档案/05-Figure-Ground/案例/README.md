# 05 图形—背景关系｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 美国地图上用白色陆地区域与蓝灰背景分开地形，再以深色点标示都市区，并让重点营收数字跳出背景。此为与已入库 Fortune 500 案例关联的机制分析。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 明度差、边缘清晰度、空间位置以及负空间会影响图形优先级；图底反转会改变主体识别。

**教学前后对照：**
- 待修改版：地图、辅助网格、所有圆与长段注释同等强度，读者缺乏视觉入口。
- 建议修改版：降低非关键底图对比、保留主体点和关键数字的清晰边缘，并维持可读图例。

**叙事目标：** 主体进入→地图或上下文定位→阅读解释文本。前景突出不改变对象的统计地位。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

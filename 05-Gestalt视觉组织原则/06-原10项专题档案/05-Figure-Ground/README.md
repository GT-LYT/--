# 05 图形—背景关系｜Figure–Ground

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**观察者会把视场中的某些部分知觉为需要关注的主体（图形），其余部分作为背景；二者关系可随对比、包围和注意而改变。**

- **作用机制：** 明度差、边缘清晰度、空间位置以及负空间会影响图形优先级；图底反转会改变主体识别。
- **原则类别：** 前景与背景分化。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：重点点位对比背景更强；线：主数据线高对比，网格线低对比；面：分离地图陆地与背景；色彩：焦点/背景明度层级；文字：注释可读但不压过关键数据。

## 三｜视觉叙事
主体进入→地图或上下文定位→阅读解释文本。前景突出不改变对象的统计地位。

## 四｜典型应用与反例
- **教学分析情境：** 美国地图上用白色陆地区域与蓝灰背景分开地形，再以深色点标示都市区，并让重点营收数字跳出背景。此为与已入库 Fortune 500 案例关联的机制分析。
- **反例／误用：** 把背景上的小比例地区颜色变淡到几乎消失，造成选择性隐瞒。
- **可用性边界：** 浅色文字置于浅背景导致对比不足；反转过度使重点图符和背景难以区分。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对前景与背景分化的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 缩略图识别第一视觉焦点，灰度检查、文本对比检查和地图小点可见性检查。

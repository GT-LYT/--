# 05 图形—背景关系｜设计分析

## 1. 机制识别
明度差、边缘清晰度、空间位置以及负空间会影响图形优先级；图底反转会改变主体识别。

## 2. 图形变量拆解
点：重点点位对比背景更强；线：主数据线高对比，网格线低对比；面：分离地图陆地与背景；色彩：焦点/背景明度层级；文字：注释可读但不压过关键数据。

## 3. 视觉叙事架构
主体进入→地图或上下文定位→阅读解释文本。前景突出不改变对象的统计地位。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 地图、辅助网格、所有圆与长段注释同等强度，读者缺乏视觉入口。 | 降低非关键底图对比、保留主体点和关键数字的清晰边缘，并维持可读图例。 |
| 语义风险 | 把背景上的小比例地区颜色变淡到几乎消失，造成选择性隐瞒。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 浅色文字置于浅背景导致对比不足；反转过度使重点图符和背景难以区分。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 缩略图识别第一视觉焦点，灰度检查、文本对比检查和地图小点可见性检查。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。把背景上的小比例地区颜色变淡到几乎消失，造成选择性隐瞒。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

# 02 相似律｜Law of Similarity

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**形状、颜色、尺寸、方向或纹理等视觉属性相似的元素倾向于被归为一类，即使它们相距较远。**

- **作用机制：** 相同的形态和色彩形成跨位置的类别匹配线索；相似性不自动说明数据数值相等。
- **原则类别：** 外观相似型分组。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：同类统一点形；线：同一系列线型一致；面：同类统一纹理；色彩：同一类别固定色相并配文字或图例；字体：相同信息层级统一字重。

## 三｜视觉叙事
先识别类别图例，再跨位置追踪同类，最后比较不同地区。

## 四｜典型应用与反例
- **教学分析情境：** 一张跨地区的疫苗接种比较图中，所有年份的同一剂次都使用相同符号与图例，读者可跨位置寻找同一类别。
- **反例／误用：** 仅因政治地理距离近就为不同类别使用相同颜色，造成错误结盟或类别推断。
- **可用性边界：** 仅使用红绿区分时，在灰度打印或色觉差异情境下会失效。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对外观相似型分组的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 进行不看图例的类别配对、黑白模式辨认和颜色对比度检查。

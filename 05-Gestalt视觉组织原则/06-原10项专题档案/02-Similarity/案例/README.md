# 02 相似律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 一张跨地区的疫苗接种比较图中，所有年份的同一剂次都使用相同符号与图例，读者可跨位置寻找同一类别。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 相同的形态和色彩形成跨位置的类别匹配线索；相似性不自动说明数据数值相等。

**教学前后对照：**
- 待修改版：同一类别在每个区域随机换色，用户难以跟踪类别。
- 建议修改版：同一类别跨所有区域固定颜色与形状，添加清晰图例和必要文字。

**叙事目标：** 先识别类别图例，再跨位置追踪同类，最后比较不同地区。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

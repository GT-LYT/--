# 02 相似律｜设计分析

## 1. 机制识别
相同的形态和色彩形成跨位置的类别匹配线索；相似性不自动说明数据数值相等。

## 2. 图形变量拆解
点：同类统一点形；线：同一系列线型一致；面：同类统一纹理；色彩：同一类别固定色相并配文字或图例；字体：相同信息层级统一字重。

## 3. 视觉叙事架构
先识别类别图例，再跨位置追踪同类，最后比较不同地区。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 同一类别在每个区域随机换色，用户难以跟踪类别。 | 同一类别跨所有区域固定颜色与形状，添加清晰图例和必要文字。 |
| 语义风险 | 仅因政治地理距离近就为不同类别使用相同颜色，造成错误结盟或类别推断。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 仅使用红绿区分时，在灰度打印或色觉差异情境下会失效。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 进行不看图例的类别配对、黑白模式辨认和颜色对比度检查。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。仅因政治地理距离近就为不同类别使用相同颜色，造成错误结盟或类别推断。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

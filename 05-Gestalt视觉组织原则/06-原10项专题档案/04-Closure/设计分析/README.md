# 04 闭合律｜设计分析

## 1. 机制识别
视觉依据已知轮廓趋势和内部/外部边界关系推断整体；补全属于知觉，不等于补齐不存在的观测数值。

## 2. 图形变量拆解
点：虚点围合出暗示区域；线：允许轮廓留缺口但保持识别；面：利用负空间呈现闭合形；色彩：图底对比确保轮廓可辨；图符：利用缺口简化象形符号。

## 3. 视觉叙事架构
先从简化轮廓识别主题，再进入文字与数值证据；不适合让读者凭补全猜缺失数据。

## 4. 对照分析
| 维度 | 可能的问题状态 | 可操作的改版策略 |
|---|---|---|
| 图面证据 | 复杂轮廓细节太多，主体难以辨认。 | 删除非关键轮廓段，留下可被认出的关键边缘，同时保留数值文字。 |
| 语义风险 | 把缺测地区的统计图空缺画成连续封闭图，掩盖数据缺失。 | 在数据层核对实体关系与数值口径，增设必要说明 |
| 可访问性 | 轮廓线索过少、背景复杂或缩放过小时无法可靠补全。 | 通过文字、线型、留白和尺寸提供非颜色的辅助识别 |
| 反馈评估 | 尚无真实受访者数据 | 无标题展示符号，记录参与者的形状识别率；检查是否误以为缺测值完整。 |

## 5. 反例的判定标准
**反例不是“视觉上不好看”，而是“知觉暗示与数据语义不一致”**。把缺测地区的统计图空缺画成连续封闭图，掩盖数据缺失。

**设计实践警戒：** 如果图面营造分组/连接/连续，而数据表找不到可支持的同组、连接或连续字段，应改版或增加说明，不应倒推数据关系。

## 6. 01 与 02 分类的独立性
先判断数据到底按时间、层级、类别、字母键或地理位置组织；再判断使用比较、列表、地图、混合等何种表现；最后讨论本规则如何改善编码和叙事。两种分类及本规则都是不同维度，**不得互相替换**。

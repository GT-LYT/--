# 04 闭合律｜案例记录

## 案例 A｜教学分析情境（非现成作品）
**情境：** 一组城市环保主题中的循环箭头标识使用不闭合的环形轮廓，用户仍能识别循环构型；数据量另用数字注明。

**01 数据逻辑判断：** 须根据实际案例中的字段和数据组织确认，**不得仅凭此 Gestalt 原则决定**；例如该情境可能分别出现在编目型、地理型或编年型图形中。

**02 表现形式判断：** 须根据图形实际组织方式判断（例如比较型、混合型、地标型或时间轴型），不能把 Gestalt 当成第十八个标签。

**视觉机制：** 视觉依据已知轮廓趋势和内部/外部边界关系推断整体；补全属于知觉，不等于补齐不存在的观测数值。

**教学前后对照：**
- 待修改版：复杂轮廓细节太多，主体难以辨认。
- 建议修改版：删除非关键轮廓段，留下可被认出的关键边缘，同时保留数值文字。

**叙事目标：** 先从简化轮廓识别主题，再进入文字与数值证据；不适合让读者凭补全猜缺失数据。

**证据状态：** 本情境用于演示设计判断，未提供原作图像或测量数据，**不列为已核实真实案例**；只用于制作与课堂讨论。

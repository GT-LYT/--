# 04 闭合律｜Law of Closure

> **状态：已确认的知识条目（2026-11-26）。** 本条用于信息可视化研究与设计；定义是对设计研究资料的中文概括，并非某一文献逐字翻译。案例中的教学场景是**分析情境/拟议改版**，未声称真实采样或完成用户测试。

## 一｜概念定义
**当不完整的轮廓仍提供足够的形状线索时，人们可能在感知中补全缺失部分，把片段识别为完整形状。**

- **作用机制：** 视觉依据已知轮廓趋势和内部/外部边界关系推断整体；补全属于知觉，不等于补齐不存在的观测数值。
- **原则类别：** 缺失轮廓补全。
- **适用范围：** 信息图形的分组、图例匹配、阅读路径、区块结构等；不能取代「01 五类数据逻辑」或「02 表现形式标签」。
- **证据边界：** 感知到的组合是图面的编码效果，不等于数据天然具有类别、因果、数值或流向上的关系。

## 二｜视觉编码（点、线、面、色彩与排版）
点：虚点围合出暗示区域；线：允许轮廓留缺口但保持识别；面：利用负空间呈现闭合形；色彩：图底对比确保轮廓可辨；图符：利用缺口简化象形符号。

## 三｜视觉叙事
先从简化轮廓识别主题，再进入文字与数值证据；不适合让读者凭补全猜缺失数据。

## 四｜典型应用与反例
- **教学分析情境：** 一组城市环保主题中的循环箭头标识使用不闭合的环形轮廓，用户仍能识别循环构型；数据量另用数字注明。
- **反例／误用：** 把缺测地区的统计图空缺画成连续封闭图，掩盖数据缺失。
- **可用性边界：** 轮廓线索过少、背景复杂或缩放过小时无法可靠补全。

## 五｜设计操作流程
1. 先定义数据实体、字段、语义关系及读者任务。
2. 识别本原则最相关的视觉变量；画出“目前版”和“目标版”。
3. 保持数据、指标、单位、分母、分类不变，只对缺失轮廓补全的实现做单变量优先调整。
4. 对比两版的误读风险、视觉层级及可访问性。
5. 记录后续真实读者测试，分开呈现设计预期与实测结果。

**本原则的可执行检验：** 无标题展示符号，记录参与者的形状识别率；检查是否误以为缺测值完整。

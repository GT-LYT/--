# 05｜Gestalt视觉组织原则

Gestalt 讨论观看者为什么将点、线、面、色彩、文字和运动知觉为群组、形状与图底。**不是 01 的新型数据逻辑，也不是 02 的市场表现标签。** 结构借鉴 [参考库的 Gestalt 模块](https://github.com/fengbaifan/Infographic-Style-Repository/tree/main/05-Gestalt视觉组织原则)。

## 收录数量与用户确认状态
Gestalt 并无公认的唯一固定法则数。本库此前经用户确认 **10 项**并保存完整档案；参考库研究框架列 **12 项**。为兼容参考库的研究索引，另建立 **同步律（G07）与平行律（G10）两项扩展条目**，不把它们冒充用户之前确认过的内容。

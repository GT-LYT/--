## A 数据组织
作者明确使用方块间距、横/纵留白对照，展示相同元素如何因分组间距变化而被看作两组或四组；同文附实际界面应用示例。

## B 统计方法与计量边界
此处关注感知组织而非统计数值；未获得原作可复算的数据表，不能将视觉距离、颜色或面积估算为真实数值。

## C 视觉编码
空间距离作为分组通道；组间距大于组内距，借空白实现无边框组织，分割线与卡片为对照形式。

## D 数据架构及复现字段
建议记录 work_id, element_id, group_id, visual_cue, design_variant, source_url；需要真实读者实验时独立建立 participant_id、task_id 和 response 字段。

## E 视觉叙事
先看到均匀元素→调整横纵间距→读者形成类别分组→应用于实际图文模块。

## 误读风险与设计实践
这是站酷原创设计教学文章，不是独立的定量信息图海报。归入G01的原理示例，不虚构测试数据；不计入严格‘独立信息图作品’配额。

## A 数据组织
原文通过背景浅灰网格、数据线/点和坐标轴的粗细强弱对比，以及负空间网格的示意图解释统计图主次。

## B 统计方法与计量边界
此处关注感知组织而非统计数值；未获得原作可复算的数据表，不能将视觉距离、颜色或面积估算为真实数值。

## C 视觉编码
数据点和线作为图形，降低刻度线与网格的对比，使底层参照不遮蔽主体；另用线宽、明度形成层级。

## D 数据架构及复现字段
建议记录 work_id, element_id, group_id, visual_cue, design_variant, source_url；需要真实读者实验时独立建立 participant_id、task_id 和 response 字段。

## E 视觉叙事
先定位主要数据→利用退后的刻度线确认数据尺度→阅读说明与结论。

## 误读风险与设计实践
是设计教学文章的统计图示例，非原创独立完整信息图作品；不算独立海报配额。

建议实践：核对图面→确认对象与来源→分解字段和编码→绘制设计结构图→对照前后布局/符号方案→验证阅读理解→回写Gestalt或ISOTYPE方法，不伪造已开展的实验。

# 仓库启动入口

用户要求「启动风格分析和克隆系统」时，先读本目录的 `STYLE_CLONE_SYSTEM.md`。它是本系统的运行规范。根据用户本轮指明的参考、档案和任务执行。用户未提供风格时，先报告可用入口与所需材料。仓库示范文件用于理解结构。

以下命令以本目录为工作目录。

常规入口：

1. 提取风格时，给出参考证据、风格档案与四版通用模板。
2. 应用、扩展、换题或可适用的修订时，先确认实际风格版本，建立一份 `prompt_spec` 再导出四版。
3. 能运行 Python 时，用 `python3 tools/prompt_package.py <spec.json> --profile <profile.json> --out <新输出目录>` 验证并导出。只有用户明确要求且具备能力时才生成图像。
4. 记忆入口见 `MEMORY_CARD.md`。这里的仓库指南在用户请求执行此系统时适用。

# C3 · 完成度子系统

## 目标

哪里细画，哪里简化或省略？

## 输入

参考图、主焦点、交付尺寸。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 比较不同对象的细节量。
2. 定位高完成度和简化区。
3. 为新主题重新分配绘制预算。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `C3`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为完成度分区、细节预算和最小可读部位。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

题材元素可以变化，细节聚焦方式需保持。局部有细节，远看大形不被等量细节冲散。实际生成图缺失时，图像验收状态为 `not_generated`。

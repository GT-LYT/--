# E3 · 视觉张力子系统

## 目标

哪些对比共同制造情绪和运动？

## 输入

参考图、情绪目标、其余系统的输出。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 列出可见对比及位置。
2. 说明对比之间的关系与叙事作用。
3. 选择换题后仍成立的组合。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `E3`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为张力对照表、情绪映射和冲突条件。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

对比载体可以变化，情绪功能和主次级别要复核。至少两组具体可见对比支持情绪判断，避免只写抽象形容词。实际生成图缺失时，图像验收状态为 `not_generated`。

# C1 · 绘画语言子系统

## 目标

线、笔触、色块及塑形方式如何配合？

## 输入

参考图局部、目标媒介或生成能力。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 记录线重和节奏。
2. 标记色块、渐变、笔触的分工。
3. 避免把风格名替代可见描写。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `C1`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为线质与色块规则、局部分配和生成指令。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

纹样内容可以变，笔触与色块之间的关系需保持。放大看结构线和装饰线是否分工清楚。实际生成图缺失时，图像验收状态为 `not_generated`。

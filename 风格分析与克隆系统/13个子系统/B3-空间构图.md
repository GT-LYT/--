# B3 · 空间构图子系统

## 目标

主体、前后层、遮挡与留白怎样组织观看？

## 输入

参考图、画幅、目标主体与文字要求。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 划分大形、层次和相对位置。
2. 画出阅读路径。
3. 标明必须保留和可变的空间关系。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `B3`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为布局关系图、观看路径、裁切约束。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

具体场景和视角可变，主次关系及关键路径需重新建立。缩略图能读出入口、主焦点和停留点；变画幅后复核裁切。实际生成图缺失时，图像验收状态为 `not_generated`。

# A1 · 风格本体子系统

## 目标

这组参考的可识别表现方式是什么，适用边界在哪里？

## 输入

参考图、用途与受众、其他十二系统的关键证据。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 区分题材名称与表现方式。
2. 列出至少三项可见识别关系。
3. 划定单图候选或多图确认范围。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `A1`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为媒介表征、叙事立场、识别锚点、适用任务与边界。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

人物、品牌、物件名称可以换，表现关系及适用范围需复核。遮住项目名称后仍能描述其可见识别关系；单图不宣称创作者通用风格。实际生成图缺失时，图像验收状态为 `not_generated`。

# B4 · 尺度关系子系统

## 目标

大形与小形怎样形成地位、距离和叙事压力？

## 输入

参考图、主体数量、画幅。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 比较主形、角色、环境和文字的相对大小。
2. 说明尺度差的叙事功能。
3. 迁移至新对象。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `B4`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为相对尺度表、主次级别、适配阈值。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

对象可替换，尺度层级及其情绪功能保持一致。小图可辨主要尺度差；新对象仍可识别。实际生成图缺失时，图像验收状态为 `not_generated`。

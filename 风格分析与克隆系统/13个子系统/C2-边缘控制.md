# C2 · 边缘控制子系统

## 目标

哪些轮廓清晰，哪些边缘软化、断裂或消隐？

## 输入

参考图、关键对象与可读性目标。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 按区域标记边缘强弱。
2. 说明边缘怎样建立焦点与层次。
3. 规定新主体和脸部的保护区。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `C2`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为边缘地图、保护区、允许破碎区。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

具体边缘对象随主题变化，清晰度层级需保留。关键表情、文字及接触点可读；非重点区允许变化。实际生成图缺失时，图像验收状态为 `not_generated`。

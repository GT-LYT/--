# E2 · 视觉锚点子系统

## 目标

首读、转移和停留点在哪里？

## 输入

参考图、任务目的、图文层级。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 找首读大形、次级锚点和最终停留点。
2. 指出引导线及反差来源。
3. 换题后重新指定承担对象。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `E2`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为锚点序列、注意力路径和验收顺序。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

对象可换，视觉任务与阅读顺序需可解释。缩略图和近看分别核对入口及最终停留点。实际生成图缺失时，图像验收状态为 `not_generated`。

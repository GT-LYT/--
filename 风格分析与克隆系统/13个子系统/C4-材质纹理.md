# C4 · 材质纹理子系统

## 目标

可见的表面纹理分布在哪里，能确认什么材料？

## 输入

参考图局部、目标载体和生成后端。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 记录颗粒、纤维、反射和磨损的可见表现。
2. 标注工艺推断。
3. 根据新物件选择纹理承载区。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `C4`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为可见纹理清单、推断标记和区域参数。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

纹理来源可换，粗细、分布与主次关系需复核。避免无证据的精确材质断言；纹理不遮挡脸和文字。实际生成图缺失时，图像验收状态为 `not_generated`。

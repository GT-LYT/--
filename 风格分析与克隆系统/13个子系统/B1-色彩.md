# B1 · 色彩子系统

## 目标

哪些区域使用主色、辅色和强调色，它们承担什么功能？

## 输入

参考图、区域划分、目标主题及必要品牌色。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 记录各区域的色相、明度、饱和度和冷暖。
2. 确定面积及强调色分工。
3. 将分工映射给新题材物件。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `B1`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为色彩角色表、相对面积、变体范围和冲突清单。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

物件和具体色值可随主题调整；核心色彩关系须保留或建立派生。缩略图核对强调区与主焦点一致；无依据时不写精确色值。实际生成图缺失时，图像验收状态为 `not_generated`。

# D1 · 主体设计子系统

## 目标

主体是谁，在做什么，与器物和环境如何接触？

## 输入

参考图、人物或产品要求、目标主题。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 记录数量、动作、视线、接触和遮挡。
2. 分离身份内容与关系结构。
3. 给新题材确定承担对象。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `D1`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为主体关系表、动作与接触要求、主题锁定。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

人物身份和物件可变，关键关系需明确承载。数量、动作、接触和情绪线索都能在成图中辨认。实际生成图缺失时，图像验收状态为 `not_generated`。

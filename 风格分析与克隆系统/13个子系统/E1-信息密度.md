# E1 · 信息密度子系统

## 目标

密集和稀疏区域如何分配？

## 输入

参考图、文字与主体区域、输出尺寸。缺少图像或关键任务时标记 `pending`，不得填充虚构证据。

## 执行

1. 按区域标记细节密度。
2. 区分画面密度与单个对象完成度。
3. 为新题材保留可读停顿区。

每条判断记录 `observation`、`inference`、`user_requirement` 或 `design_choice`，并标出参考 ID 与区域。用「可见特征 → 功能 → 可迁移关系 → 允许变化 → 验收」写可引用规则。

## 输出合同

写入统一 `style-profile.json` 的 `analysis`，`module` 固定为 `E1`，保留 `state`、`observations`；确有可复用关系时写入 `rules`，使用唯一规则 ID、证据、条件、优先级、依赖和检查方法。本子系统的专属结果为疏密地图、保护区和局部细节上限。可单独调用，之后与其他系统的结果合并，避免覆盖现有规则。

## 换题与验收

主题装饰可换，疏密节奏与阅读空间须复核。缩小后文字与面部可读，放大后密集区有组织。实际生成图缺失时，图像验收状态为 `not_generated`。

# 05 叙事框架：世界总量 → 集中程度 → 谁构成前十 → 解释边界

| 阶段 | 字段组合 | 问题 | 视觉模块 |
|---|---|---|---|
| 标题/研究对象 | year + indicator + unit | 讨论的到底是什么？ | 2024 GDP · 现价美元 |
| 世界参照 | WORLD_GDP + TOP10_GDP + REST_WORLD_GDP | 前十占世界多少？ | 100%堆积构成条 |
| 核心主体 | economy_zh + gdp_usd_million | 哪些经济体贡献较大？ | 前十规模横条，以0为共同起点 |
| 双强对照 | USA + CHN | 美国和中国的份额各多大？ | 数据标签和图中突出 |
| 解释限制 | indicator + source_release | 能否据此推出政治权力？ | 注明“不是影响力指数”，以及名义GDP口径 |

**读图顺序：** 问题 → 世界总量 → 前十/其余世界结构 → 前十经济体横向比较 → 来源和局限。不得把经济规模大直接标成“国际影响力强”。

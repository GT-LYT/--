# 03-统计图形分析

本目录从源数据表出发，研究信息图形借用了什么统计图形、数据怎样计算、结果如何编码，以及图形在什么条件下会误导。统计图形是表达工具，不是五种基础信息组织逻辑之外的新分类。

## 仓库导航

- [01-信息图形数据逻辑](../01-信息图形数据逻辑/)：判断信息按时间、层级、类别、字母索引还是地理空间组织。
- [02-信息图形类型案例](../02-信息图形类型案例/案例索引.md)：查找作品来源和案例分析。
- **03-统计图形分析**：解释案例中的具体统计图，分析范围以单张图或单个版块为单位。

## 分析记录框架

| 项目 | 记录内容 |
|---|---|
| 源数据结构 | 一行代表什么；哪些字段是类别、日期或数值；记录单位、粒度与来源。 |
| 转换与聚合 | 说明筛选、去重、分组及计算过程。区分计数、求和与占比；占比要写清分母。 |
| 视觉编码 | 指出位置、长度、面积、颜色各对应哪个字段，注明基线、尺度和图例。 |
| 适用边界 | 检查缺失值与零值是否区分、比较口径是否一致；无量化数据的结构图不强行归为统计图。 |
| 案例证据 | 链接到 02 的作品，注明分析的是哪个版块。区分原图可见信息与复现建议；原数据不可得时不推定原作者的计算方法。 |
